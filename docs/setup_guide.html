🗄️ Step 2: Database Import in MySQL
2.1 Create & Import Database MySQL

Open PowerShell/Terminal in the Smart_Nutrition_Migration folder and execute:

# Create Database
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS smart_nutrition_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# Import Full Database Dump
mysql -u root -p smart_nutrition_db < smart_nutrition_db_full_dump.sql
⚠️ IMPORTANT: The database name MUST be smart_nutrition_db so microservice database connections connect seamlessly without code changes.
🔑 Step 3: Configure Local Database Password & Secrets
3.1 Update secrets.properties Configuration

Open smart-nutrition-backend/secrets.properties and update DB_PASSWORD to match your local MySQL password:

GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE
DB_USERNAME=root
DB_PASSWORD=YOUR_LOCAL_MYSQL_PASSWORD
📦 Step 4: Install Frontend Dependencies
4.1 Run npm install Frontend

Open PowerShell in the frontend directory and install packages:

cd smart-nutrition-frontend
npm install
